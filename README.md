# iPosters 💎

**iPosters** — это универсальный веб-сервис, объединяющий в себе полезную информацию, интересные факты, календарь праздников, актуальные статьи. Все самое важное — на одной платформе.

---

## ✨ Основные возможности
*   **Посты:** На iPosters вы можете опубликовать свой пост или почитать другие посты.
*   **Факты:** Рандомайзер фактов не даст заскучать!
*   **🎉Праздники:** Удобный виджет для просмотра дня недели и праздника.
*   **💡Инфо-блок:** Популярные статьи и статистика.
## 🔧Инструменты
*   **Публикация постов**
*   **👍Оценка статей лайками и комментариями**
## 🚀 Технологии
В проекте использовались:
*   **💻Frontend:** HTML5, CSS3, JavaScript.
*   **⚙️Backend:** Node.js, Supabase.
